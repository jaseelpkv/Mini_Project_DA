# Mini_Project_DA
# Movie Analytics Dashboard (Power BI) data cleaning and visualization done for DA33

An interactive Power BI dashboard built on an IMDb-style movie dataset to explore film performance, audience engagement, and production trends. The project uses data cleaning, relational modeling, DAX measures, and AI-powered visuals to uncover insights across genres, ratings, revenue, and viewer behavior.

## Project Overview

This dashboard analyzes a movie dataset containing details such as title, year, genre, duration, IMDb score, budget, gross revenue, content rating, aspect ratio, audience votes, and social engagement.

The goal of the project is to transform raw movie metadata into a structured analytical model and deliver meaningful business and entertainment insights through interactive visualizations.

## Key Features

* Cleaned and transformed raw movie data using excel and Power Query
* Built a relational data model 
* Created DAX measures for KPIs and analysis
* Designed an interactive dashboard with slicers and drill-based exploration
* Used Power BI AI visuals such as:

  * Key Influencers
  * Decomposition Tree

## Project Outcome

This project demonstrates end-to-end business intelligence workflow:
data cleaning, transformation, modeling, KPI design, interactive dashboarding, and AI-assisted insight generation using Power BI.

It is designed as a portfolio project to showcase practical analytics, storytelling, and dashboard development skills.
